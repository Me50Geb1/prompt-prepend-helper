# Changelog

## 1.0.0 - 2026-09-01

Initial public release.

### Added

- Additional Positive Prompt field
- Prepend additional prompt during generation
- Enable / disable additional prompt
- Positive Prompt only clear function
- Positive Prompt Style registration
- Duplicate tag detection
- Duplicate removal between additional and original prompts
- Underscore / space normalized duplicate detection
- Weighted tag duplicate detection
- Natural-language exclusion from duplicate processing
- txt2img support
- img2img support

### Compatibility

- Designed for sd-webui-forge-neo
- Designed to coexist with Z-Tipo and other prompt-related extensions
